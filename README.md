# Українізатор для Microsoft Flight Simulator 2024

**MSFS2024 Ukr** — неофіційний українізатор текстового інтерфейсу та ігрових текстів для **Microsoft Flight Simulator 2024**.

Проєкт створений для українських гравців. Переклад формується на основі машинного перекладу з подальшим ручним редагуванням та поступово покращується спільнотою.

## Можливості

- український переклад текстів гри;
- ручне редагування та покращення машинного перекладу;
- можливість запропонувати виправлення через Pull Request;
- готові інсталятори;
- готові архіви для ручного встановлення;
- оновлення перекладу відповідно до змін у грі.

Переклад може містити неточності, невдалі формулювання або одруківки. Якщо ви знайшли помилку — повідомте про неї або запропонуйте виправлення.

У деяких частинах гри окремі слова або фрази можуть залишатися мовою оригіналу. Це може бути пов'язано з тим, що відповідний контент завантажується або оновлюється грою окремо.

## Встановлення

Є два способи встановлення українізатора.

### 1. Через інсталятор (найпростіший)

Завантажте відповідний інсталятор:

- `MSFS2024Ukr_en.exe`
- `MSFS2024Ukr_ru.exe`
- `MSFS2024Ukr_pl.exe`

Запустіть інсталятор і дотримуйтесь його інструкцій.

Після встановлення виберіть у грі відповідну мову.

### 2. Через архів

Завантажте відповідний архів:

- `MSFS2024ukr-en.zip`
- `MSFS2024ukr-ru.zip`
- `MSFS2024ukr-pl.zip`

Розпакуйте вміст архіву в папку, де встановлена гра.

Типові шляхи:

**Steam:**

```text
C:\Program Files (x86)\Steam\steamapps\common\Microsoft Flight Simulator 2024
```

**Microsoft Store / Xbox App:**

```text
C:\XboxGames\Microsoft Flight Simulator 2024\Content
```

У грі виберіть ту мову, для якої було встановлено українізатор.

Наприклад:

- `MSFS2024ukr-en.zip` → у грі виберіть **English**;
- `MSFS2024ukr-pl.zip` → у грі виберіть **Polish**.

## Перед встановленням

Рекомендується зробити резервну копію оригінальних файлів гри.

Українізатор змінює файли локалізації у встановленій копії гри. Оновлення Microsoft Flight Simulator 2024 можуть замінити або змінити ці файли.

Після великих оновлень гри рекомендується перевірити розділ [Releases](../../releases) та встановити актуальну версію українізатора.

## Для тих, хто хоче допомогти

Внесок у переклад вітається.

Рядки перекладу знаходяться в:

```text
MSFS2024Ukr/data
```

Ви можете:

- створити Issue з описом помилки;
- запропонувати виправлення;
- створити Pull Request;
- запропонувати кращий варіант перекладу;
- допомогти з тестуванням.

Будь ласка, під час редагування перекладу намагайтеся зберігати зміст оригіналу та враховувати контекст гри.
